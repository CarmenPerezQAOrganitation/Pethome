# 🐾 PetHome

Proyecto personal para practicar **QA Manual** y **QA Automation**.

PetHome es una tienda online ficticia de productos para mascotas creada con el objetivo de simular un proyecto real sobre el que realizar pruebas manuales y automatizadas.

## 🎯 Objetivos

Este proyecto permite practicar todo el ciclo de trabajo de un QA:

- Diseño de historias de usuario
- Criterios de aceptación
- Casos de prueba en Gherkin
- Gestión de pruebas
- Reporte de bugs
- Pruebas funcionales
- Pruebas exploratorias
- Pruebas de regresión
- API Testing con Postman
- Automatización con Playwright
- Integración continua con GitHub Actions
